# ImgComment · Excel 图片批注工具

## 一、软件简介

ImgComment 是一款 Windows 桌面小工具，可以在 Excel 单元格中**快速插入图片批注**。  
图片保持原始分辨率和纵横比，不压扁不拉伸。

---

## 二、安装方法

1. 把 `ImgComment.exe` 放到任意文件夹（桌面即可）
2. **无需安装、无需注册、无需管理员权限**
3. 双击运行即可使用

---

## 三、使用前提

打开 Excel：

> **文件 → 选项 → 常规**
> **取消勾选「启用新式批注」** → 确定

> ✅ 如果已经取消了这个选项，直接使用即可
> ❌ 如果没取消，插入的图片批注会**不可见**

## 五、功能详解

### 📷 插入 / Insert

**作用：** 从电脑里选一张图片，插入到当前选中单元格的批注里

**操作：**
1. 在 Excel 中点选一个单元格
2. 点击「📷 插入 / Insert」按钮
3. 在弹出的文件选择框里选一张图片（.jpg/.png/.bmp）
4. 图片自动插入到批注中

**特点：**
- 图片保持原始尺寸（不缩小不放大）
- 锁定纵横比（不压扁不拉伸）
- 如果该单元格已有批注，自动替换

---

### 📋 粘贴 / Paste

**作用：** 把剪贴板里的图片粘到批注里

**操作：**
1. 先截图（按 Win+Shift+S 或 Ctrl+Shift+S）或复制一张图片
2. 在 Excel 中点选一个单元格
3. 点击「📋 粘贴 / Paste」按钮

**特点：**
- 支持任何截图工具截的图
- 不需要先存成文件
- 自动处理剪贴板图片格式

---


### ℹ 帮助 / Help

**作用：** 弹出帮助信息窗口

**内容包含：**
- 功能说明
- 使用步骤
- 重要前提提醒

---

### ✕ 退出 / Exit

**作用：** 关闭 ImgComment 工具

> 点窗口右上角红叉也可以关闭

## 六、注意事项

| 事项 | 说明 |
|------|------|
| **Excel 版本** | 全版本通用（2007～Office 365） |
| **禁用新式批注** | ⚠ 必须！文件→选项→常规→取消勾选 |
| **图片格式** | 支持 .jpg、.jpeg、.png、.bmp |
| **图片大小** | 不限制，图片多大批注就多大 |

| **Excel 是否要先开** | 推荐先开 Excel → 再开工具 |
| **可以不开 Excel 直接开工具吗** | 可以，工具会自动启动 Excel |

## 七、常见问题

### Q：插入了图片，但批注里看不到？
A：没有关闭「新式批注」。请去
> 文件 → 选项 → 常规 → 取消勾选「启用新式批注」

### Q：按钮点不动？
A：试试点一下 Excel 窗口让它获得焦点，再点工具按钮。

### Q：退出后下次还要重新双击吗？
A：是的，每次用都需要双击运行。工具不驻留后台。

### Q：这个工具会修改我的 Excel 文件吗？
A：**会**。插入批注后，Excel 文件会保存批注内容。建议操作前先备份文件。

### Q：需要联网吗？
A：插图片不需要。只有点击「帮助」时才需要联网打开浏览器。
